# Backyard Bet

Мультиплеерный пати-гейм на вылет: блеф на костях за столом во дворе плюс
физические мини-игры между раундами. До 4 игроков.

## Требования

| | Версия |
|---|---|
| Unity | 6000.5.10f1 |
| Netcode for GameObjects | 2.13.2 |
| Multiplayer Services (Relay/Lobby) | 2.3.1 |
| Blender (для пересборки карты) | 5.2.1 LTS |
| Git LFS | обязателен — иначе вместо моделей приедут текстовые заглушки |

## Как развернуть

```bash
git lfs install
git clone https://github.com/AlamadeStudios/Backyard-Bet-experiment.git
```

Открыть папку как проект в Unity Hub. Первое открытие долгое: Unity заново
собирает `Library/`, которой в репозитории нет.

Дальше открыть сцену `Assets/BackyardBet/Scenes/Backyard.unity` и нажать Play.

## Как играть

| Клавиша | Действие |
|---|---|
| WASD, Shift | ходьба и бег |
| Мышь | обзор |
| Пробел | прыжок |
| **E** | открыть дверь, взять предмет, сесть за стол |
| **ЛКМ** | бросить то, что в руке |
| Esc | освободить курсор |

В меню два режима. **Хост / Клиент** — игра на одной машине, работает всегда
и не требует аккаунта. Порт подбирается автоматически: редактор Unity любит
удерживать 7777 после игровой сессии.

**Создать комнату / Войти по коду** — игра по сети через Unity Relay. Требует
привязанного Cloud Project ID в `Edit → Project Settings → Services`.

## Как устроено

Сеть построена на **хост-авторитете**: решения принимает хост, клиент только
просит. Это принципиально для игры про блеф — состояние костей клиенту знать
нельзя.

* `LiarsDice.cs` — правила блефа, чистый C# без единой ссылки на Unity.
  Так их можно проверять отдельно и невозможно нарушить с клиента.
* `BluffTable.cs` — сетевая обёртка над правилами. Публичное состояние (чей
  ход, ставка, у кого сколько костей) идёт всем через `NetworkVariable`, а
  **свои кости уходят адресным RPC лично игроку**.
* `WorldBuilder.cs` — собирает мир при запуске: вешает механику на двери,
  физику на реквизит, убирает декоративных персонажей. Сделано в рантайме, а
  не пунктами меню: правки сцены терялись, если редактор держал её открытой.
* `PropNetwork.cs` — физика реквизита. Считает только хост, клиентам уходят
  позиции лишь тех вещей, что реально двигались.
* `GameRoot` — префаб с логикой партии, хост создаёт его при старте.
  Важно: он должен быть импортирован **до** запуска, иначе Netcode не
  присвоит ему идентификатор и объект молча не заспавнится.

## Карта

Вся геометрия и расстановка описаны кодом в `blender/backyard_bet.py` —
двор 76×76 м, дом с боулингом, 8 станций мини-игр, 4 персонажа. Руками
ничего не моделится.

Пересборка карты и экспорт в проект:

```bash
blender --background --python blender/backyard_bet.py -- fbx novstills
```

Готовые `BackyardBet.fbx` и `CH_*.fbx` копируются в
`Assets/BackyardBet/Map/` и `Assets/BackyardBet/Characters/`.

Флаги: `fbx` — экспорт, `novstills` — без рендера превью,
`cardsonly` — быстрый рендер только стола (для правок персонажей).
