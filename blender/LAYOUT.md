# Backyard Bet — карта и таймлайн

Генератор: [backyard_bet.py](backyard_bet.py). Запуск:

```bash
"D:/Steam/steamapps/common/Blender/blender.exe" --background --python D:/cloudi/blender/backyard_bet.py
```

Аргументы после `--`: `sheets` — собрать раскадровки анимаций, `novstills` — пропустить стоп-кадры.

## Карта (единицы = метры, начало координат — центр двора)

Забор: x ∈ [-38, 38], y ∈ [-38, 38] → участок 76×76 м.

|---|---|---|
| Дом (основной блок) | центр (-6, 26), 16×12, h 5.5 | фасад смотрит на -y |
| Пристройка-боулинг | x 2..30, y 20.5..29.5, h 4.2 | тёмные стены, лампы, неон |
| Патио | x -16..5, y 15..20 | выход из дома |
| **Стол блефа** (карты, кости, фишки) | (0, 4) | 4 персонажа вокруг, r 1.38 |
| **Бильярд** под перголой | (-18, 10) | стол 3.1×5.7, 16 шаров, кий |
| **Дартс** | мишень (20, 2), линия броска (12.2, 2) | 20 секторов, кольца, булл |
| **Бир-понг** | (-10, -12) | 2 треугольника по 6 стаканов |
| **Метание топоров** | мишень (22, -12), бросок (15.6, -12) | мишень с кольцами |
| **Рогатка + банки** | рогатка (-6, -22), стеллаж (-19, -22) | 6 банок |
| **Бассейн с пираньями** | (2, -30), r 5.5 | 5 плавников ходят по кругу |

Боулинг: дорожка от x=10 (линия) до x=24 (кегли), ширина 1.9, центр y=25.

| Кадры | Сцена | Типы анимации |

| 261–380 | Дартс | замах, баллистика, осевое вращение, втыкание, дрожь мишени |
| 381–500 | Бильярд | толчок кия, разбой, качение с вращением, падение в лузу |
| 501–620 | Бир-понг | бросок, дуга с отскоком, погружение в стакан, реакция |
| 621–740 | Топоры | замах над головой, 2.25 оборота, удар, щепки |
| 741–850 | Рогатка | натяжение жгута, выстрел, разлёт банок с кувырком (2 камеры) |

Сквозные (весь таймлайн): плавники пираний по кругу, дым от мангала циклом.

Камеры переключаются маркерами таймлайна — при проигрывании `.blend` монтаж идёт сам.

| Группа | Что |
|---|---|
| Зоны мини-игр | гравийные площадки, меловые линии броска, тюки соломы за мишенями, ящики у банок, вытоптанные пятна земли |
| Тусовка | костровище (камни, дрова, живой огонь + точечный свет), 5 брёвен-сидений, бар из поддонов с 3 кегами и табуретами, навес с пикник-столом и арбузом, палатка, гамак между двумя деревьями, 3 шезлонга, надувной круг, бумбокс |
| Игровое | табло со счётом на столбах, 4 указателя-стрелки к станциям |
| Мусор вечеринки | 74 стакана/банки/бутылки/тарелки, половина опрокинута — скаттер кольцами вокруг стола, костра, бара и бир-понга |
| Зелень | 56 кустов, 210 пучков травы, 96 цветов, 34 камня, плотная посадка вдоль забора, 9 деревьев внутри двора |
| Атмосфера | флажковая гирлянда по всему периметру забора (184 вымпела), садовые фонарики вдоль дорожки, шины, тачка, поленница, качели из шины |

Скаттер обходит станции, дом, патио и дорожку через `spot_free()`. Высокие объекты дополнительно проверяются на коридоры камер (`blocks_cam`) и на траекторию облёта (`off_flight_path`) — иначе дерево вырастает прямо перед объективом.

## Станции: деревянный кабинет вместо голой стойки

Дартс и топоры раньше стояли на паре столбов с плоским блоком позади мишени. Теперь у обеих общий хелпер `build_target_wall()` (дощатая обшивка, рама, столбы, козырёк-навес) плюс `build_wall_lamp()` (лампа над мишенью, копирует стиль ламп боулинга) и `build_chalk_scoreboard()` (грифельная доска с чирканными отметками счёта). У дартса дополнительно колчан с 3 запасными дротиками на стене.

## Дом: экстерьер и боулинг изнутри

| Место | Что добавлено |
|---|---|
| Крыльцо | коврик, 2 кашпо с растениями, подвесной фонарь над дверью (реальный источник света), табличка с номером дома |
| Крыша | водостоки вдоль обоих карнизов (дом + пристройка), статичный дымок над трубой |
| Пристройка снаружи | вывеска боулинга (табличка + иконки кегли/шара + светящаяся кромка) над окнами |
| Боулинг изнутри | 6 постеров на стенах (силуэты кегли/шара, чередуются по цвету), диско-шар под потолком, счёт на табло — цифры «12:08» через свой pixel-шрифт `stamp_text()`/`DIGIT_FONT`, 2 скамьи в лобби, полка для обуви с 5 парами, снек-стойка со стаканами и попкорном |

Важный нюанс с `stamp_text()`: пиксели цифр — это отдельные тонкие боксы, которые должны стоять **перед** лицевой гранью светящейся панели, а не внутри её объёма — иначе они целиком скрыты в сплошном меше и не рендерятся.

## Технические заметки

- Blender 5.x: fcurves лежат в `action.layers[0].strips[0].channelbags[0].fcurves`, старый `action.fcurves` удалён — см. `fcurves_of()`.
- Маркеры камер перебивают `scene.camera` при рендере, поэтому перед рендером стоп-кадров они очищаются (в `.blend` остаются).
- Плоские меши мишеней надо поворачивать на **-90°** по Y, иначе нормали смотрят от зрителя и мишень выходит чёрной.
- Steam-сборка Blender собрана без FFMPEG — видео пишется только PNG-секвенцией.
